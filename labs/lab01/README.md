This folder is where your work for Lab 1 goes.

### The assignment

Lab 1 gets your environment and accounts working for the rest of the term:

- Join the class Slack
- Create a GitHub **or** GitLab account (your choice — pick one and keep it all term)
- Set up a Linux environment (six options are covered in the codelab)
- Set up an IDE
- Set up your own homework repository and give me access
- Compile a multi-file C++ program and write a `Makefile` for it

### Deliverables

Commit these to `labs/lab01/` in your own repository:

- `lab01report.pdf` — your name, class number, and title at the top, plus the required screenshots
- `Makefile`
- `main.cpp`, `hello.h`, `hello.cpp`, `hello2.h`, `hello2.cpp`

Run `make clean` before committing. Do not commit compiled programs or object files.
